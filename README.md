# CV-сайт Александра

Статический одностраничный сайт-портфолио на русском языке.

## Структура

- `index.html` — контент и семантическая разметка;
- `styles.css` — адаптивный дизайн, светлая/тёмная тема и стили печати;
- `script.js` — меню, анимации, тема и обновление публичной статистики GitHub;
- `assets/alexander.webp` — фотография;
- `assets/frogeesoft-logo.png` — логотип FrogeeSoft для тёмной темы;
- `assets/frogeesoft-logo-light.png` — версия логотипа для светлой темы;
- `assets/favicon.svg` — favicon.

## Запуск

Сайт можно открыть напрямую через `index.html`. Для корректной работы запросов к GitHub API удобнее запустить локальный сервер:

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Публикация на GitHub Pages

1. Создайте новый репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. В `Settings → Pages` выберите `Deploy from a branch`, ветку `main`, папку `/root`.

## Обновление информации

Контент находится в `index.html`. Количество репозиториев, подписчиков, звёзд и форков обновляется через GitHub API, при недоступности API используются резервные значения.
