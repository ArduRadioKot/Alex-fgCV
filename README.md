# CV / Portfolio Александра

Адаптивный одностраничный сайт-портфолио.

## Запуск

Откройте `index.html` напрямую или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Структура

- `index.html` — содержимое сайта;
- `styles.css` — оформление, адаптивность и светлая/тёмная темы;
- `script.js` — переключение темы, мобильное меню, анимации и статистика GitHub;
- `assets/` — фотография, логотипы и изображения проектов.

Сайт не требует сборки и готов к публикации через GitHub Pages.
